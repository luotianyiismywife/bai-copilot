BAI for Copilot Chat uses your own BAI API key to make a variety of AI models available in the model picker.

Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `BAI: Set BAI API Key`: Set or update your API key
- `BAI: Generate Commit Message with BAI`: Generate Git commit messages

[Get an API Key](https://chat.b.ai/chat)
[Set API Key](command:bai.setApiKey)
